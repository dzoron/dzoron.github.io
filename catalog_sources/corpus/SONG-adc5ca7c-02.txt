## Song 02: Rust on the Knife

[Verse 1]  
Rust on the knife is not the knife,  
Red dust wearing an edge,  
Rain had teeth and winter hands,  
Time leaned hard on the pledge.  

Still there was steel under weather,  
Still there was shape in the scar,  
Still there was work in the handle,  
Still there was name in the bar.  

[Chorus]  
Scrape what turned, keep what holds,  
Do not crown corrosion gold.  
Lose some weight and save the blade,  
Not every layer should be saved.  

[Verse 2]  
Rust has a record, rust has a path,  
Rust has a red little throne,  
But rust is not steel taking a nap,  
Rust has a name of its own.  

So tag it and lift it and sweep it away,  
Keep the old error in sight,  
The knife is not pure because nothing went wrong,  
The knife is preserved by the rite.  

[Final Chorus]  
Scrape what turned, keep what holds,  
Do not crown corrosion gold.  
The record stays, the false path fades,  
The edge returns when rust is named.
